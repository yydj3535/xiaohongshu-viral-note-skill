# 笔记输出模板

生成笔记时严格按以下版式输出：

```
📌 标题：<≤20字，带钩子>

<正文 400–800 字>
<开头3行：痛点/结果/悬念前置>
<短句分行，一行一个意思>
<emoji 每100字2–4个>
<必须包含 1 句互动引导>

<话题标签 5–8 个，单独成段>

🖼️ 封面文案备选：<备选1> / <备选2>（各≤10字）
🕐 建议发布：<时间段>
📷 配图建议：<首图要求 + 图片数量建议>
```

## 交付前检查清单
- [ ] 标题 ≤ 20 字且有钩子
- [ ] 正文 400–800 字，开头 3 行留人
- [ ] 有明确的互动句
- [ ] 话题 5–8 个，含大流量+垂类+场景词
- [ ] 封面文案 2 个备选，各 ≤ 10 字
- [ ] 无违禁词（跑过 check_note.py）
- [ ] 自检得分 ≥ 85
