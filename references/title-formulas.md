# 标题公式库

标题 ≤ 20 字。每个公式后附真实例子，生成时直接套用句式。

## 1. 数字清单法
`数字 + 人群 + 结果`
- 3 个习惯让我的皮肤稳如磐石
- 5 分钟搞定的低卡晚餐合集

## 2. 悬念反问法
`反问 + 反常识答案`
- 月薪 5k 凭什么住得比你好？
- 谁说租房就不能有家的感觉？

## 3. 身份认同法
`人群标签 + 戳心陈述`
- 打工人的深夜治愈时刻
- 新手妈妈必看的哄睡技巧

## 4. 结果前置法
`结果 + 时间/成本`
- 7 天瘦了 4 斤，方法全在这
- 花 50 块把出租屋改成奶油风

## 5. 对比反差法
`A vs B + 出乎意料`
- 同样的工资，她的存款是我的 3 倍
- 300 块的包和 3000 块的包，差别在哪

## 6. 痛点警告法
`千万别 + 常见错误`
- 千万别这样敷面膜，全错了
- 买空气炸锅前，先看这 3 个坑

## 选标题规则
- 优先选带**具体数字**的公式，点击率最稳。
- 标题党红线：承诺必须在正文兑现，写不出兑现内容就换公式。
- 备选 2 个标题时，一个偏情绪、一个偏干货，让用户挑。
