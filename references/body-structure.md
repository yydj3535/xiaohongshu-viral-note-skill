# 正文结构库

正文 400–800 字。开头 3 行决定生死：痛点、结果、悬念三选一，必须前置。

## 种草型（产品推荐）
1. 钩子开头：我的真实困扰 / 被种草的契机（一句话）
2. 产品亮相：是什么 + 核心卖点（只讲 1 个最打动人的点）
3. 细节背书：使用场景 + 体感细节（越具体越可信）
4. 避坑提醒：适合谁 / 不适合谁（真诚感来源，必写）
5. 互动结尾：提问引导评论

## 干货型（教程攻略）
1. 钩子开头：结果前置
2. 清单主体：分点 3–5 条，每条一句话结论 + 一句话解释
3. 注意事项：2–3 个易错点
4. 互动结尾：求收藏 + 提问

## 测评型（横向对比）
1. 钩子开头：测了 N 款，总花费 X 元
2. 逐款短评：每款 2–3 句
3. 排名结论：第一名是谁、适合谁
4. 互动结尾：投票式提问

## 日常型（生活记录）
1. 钩子开头：情绪或画面感一句话
2. 故事线：起因 → 过程 → 小反转/小确幸
3. 金句收尾：一句可截图的话
4. 互动结尾：共鸣式提问

## 通用写作铁律
- 口语化，用"你"不用"您"；短句分行，一行一个意思，拒绝大段文字。
- emoji 每 100 字 2–4 个，放在段首或句尾做视觉分隔，不堆砌。
- 每篇正文必须有**明确的互动句**，没有互动句的笔记不许交付。
